# `agents/` — Agent prompt framework

**`prompts/*.md`** is the source of truth for every expert; `npm run use:claude` / `use:cursor` / `agents:sync` generate `CLAUDE.md` + `.claude/` or `.cursor/rules/*.mdc` from it — never edit the generated copies. **`template-growth`** always applies (kernel / capability / catalog). **`harvest-expert`** applies on harvest docs and scripts. Read **`README.md`** for path-scoped vs global experts (debugger, janitor), and **Tests-first feature work** (Test expert applies to `apps/api/`, `apps/web/client/`, `apps/web/app/` plus `test/**`). `registry.yaml` lists ids and globs. **Infra expert** also scopes to **`apps/web/client/lib/analytics/**`** (web analytics adapters). Scaffold does **not** codegen adapters — see **[`docs/research/scaffold-agents-and-adapters.md`](../docs/research/scaffold-agents-and-adapters.md)**.
